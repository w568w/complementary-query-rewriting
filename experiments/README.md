# Experiments

- `main_effectiveness.py`: fixed-roster effectiveness and efficiency.
- `component_ablation.py`: all supplied configurations, with paired gaps to Full.
- `prepare_ablation.py`: matched RL/memory/random/no-scope/document contexts.
- `prepare_history.py`: AOL4PS chronological event prefixes and feedback banks.
- `history_growth.py`: aggregate history-growth scores.
- `export_results.py`: export score arrays from original reports.
- `click_noise.py`: click deletion and replacement robustness.
